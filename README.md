# Portfolio 3D — Christian Valastro

Portfolio personale di Christian Valastro, web developer di Catania.

Il progetto è in fase iniziale e verrà sviluppato con React, animazioni avanzate e un'esperienza 3D responsive.

## Sviluppo locale

```bash
npm install
npm run dev
```

## Comandi

- `npm run dev` avvia l'ambiente di sviluppo.
- `npm run build` genera la versione di produzione.
- `npm run lint` esegue i controlli statici.
